SmartCoachRadar

data class SmartCoachRadar(val id: String, val name: String, val rssi: Int, val deviceType: DeviceType, val macAddress: String?, val measurementUnit: RadarMeasurementUnit, val batteryLevel: RadarBatteryLevel, val powerSource: RadarPowerSource, val modelNumber: String?, val measurementState: RadarMeasurementState = RadarMeasurementState.unknown)

A SmartCoach radar, as discovered by scanning or held by the current session.

Instances are snapshots: the SDK emits a new one through SmartCoach.sessionStateStream whenever anything about the radar changes (signal strength, battery, unit…). Compare radars with id, not ==, to tell whether two snapshots are the same physical device.
