startMeasuring

suspend fun startMeasuring(): Flow<MeasurementData>

Returns a flow of readings from the connected radar.

From SmartCoachSessionState.connected the radar is told to start measuring. From SmartCoachSessionState.measuring (for example started from the radar's button) no command is sent and the flow just delivers the readings. The flow completes on stopMeasuring, disconnect, when the radar stops by itself, or when the connection is lost.

Collect the flow promptly: readings that arrive before collection starts are not kept.

Throws

SmartCoachError

SmartCoachErrorCode.notConfigured, SmartCoachErrorCode.invalidSessionState unless connected or measuring, SmartCoachErrorCode.failedToStartMeasuring, SmartCoachErrorCode.featureNotAvailable if measuring isn't entitled for this radar model, or SmartCoachErrorCode.invalidEntitlements.
