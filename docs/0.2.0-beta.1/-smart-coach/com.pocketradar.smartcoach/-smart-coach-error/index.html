SmartCoachError

class SmartCoachError(val code: SmartCoachErrorCode, val domain: String, cause: Throwable? = null) : Exception

The only error the SDK throws from its public API. Named to match iOS; on Android it is an Exception.

Branch on code; its SmartCoachErrorCode.rawValue is the same number on iOS, so one support table covers both platforms.

try {
    SmartCoach.connect(to = radar)
} catch (e: SmartCoachError) {
    when (e.code) {
        SmartCoachErrorCode.permissionDenied -> requestBluetoothPermissions()
        SmartCoachErrorCode.failedToConnect -> showRetry()
        else -> showError(e.message)
    }
}
