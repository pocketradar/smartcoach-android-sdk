MeasurementData

data class MeasurementData(val measurement: SpeedMeasurement, val macAddress: String?, val direction: RadarDirection = RadarDirection.unknown, val velocityType: RadarVelocityType = RadarVelocityType.generic, val tilt: RadarTilt? = null)

One speed reading from the radar, delivered by the flow from SmartCoach.startMeasuring.

SmartCoach 1 radars report only the speed: direction is RadarDirection.unknown, velocityType is RadarVelocityType.generic and tilt is null.
