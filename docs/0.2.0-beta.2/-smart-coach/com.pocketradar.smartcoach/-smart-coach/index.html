SmartCoach

object SmartCoach

Entry point of the SmartCoach SDK: configure it once, scan for radars, connect, and stream speed readings. Mirrors the iOS SDK's SmartCoach API name for name.

Every function is main-safe and can be called from any coroutine. All failures are thrown as SmartCoachError. The SDK runs one session at a time; sessionStateStream is the single source of truth for where it is.

SmartCoach.configure(applicationContext)
SmartCoach.startScanning(connectToLastPairedDevice = true)
SmartCoach.sessionStateStream().first { it is SmartCoachSessionState.connected }
SmartCoach.startMeasuring().collect { data -> show(data.measurement.value, data.measurement.unit) }

Android-specific:

  • configure takes a Context.

  • The host app must request runtime permissions before scanning or connecting: BLUETOOTH_SCAN and BLUETOOTH_CONNECT on Android 12+, ACCESS_FINE_LOCATION below. The SDK declares them in its manifest. A missing one throws SmartCoachErrorCode.permissionDenied.

  • While connected, the SDK runs a foreground service and shows a notification, configured with SmartCoachDeviceConfigurationOptions.notification.

Entitlements: the API key decides which radar models the app may scan for, connect to and measure with. The SDK fetches them from Pocket Radar the first time a call needs them (so that call needs network access) and refreshes them as they expire; offline, the last ones fetched stay valid for about 21 days. A call the key doesn't allow throws SmartCoachErrorCode.featureNotAvailable; entitlements that can't be fetched or verified throw SmartCoachErrorCode.invalidEntitlements.

Link copied to clipboard
suspend fun connect(to: SmartCoachRadar)

Connects to to, usually a radar from SmartCoachSessionState.scanning. Returns once the connection has started; the radar is ready for commands when the session reaches SmartCoachSessionState.connected, which only happens once the radar's encryption handshake has finished. A handshake that fails, or doesn't finish within 10 seconds, ends in SmartCoachSessionState.disconnected with SmartCoachErrorCode.failedToConnect.
