configure

fun configure(context: Context, deviceConfigurationOptions: SmartCoachDeviceConfigurationOptions? = null)

Configures the SDK. Call once, typically from Application.onCreate, before any other call.

Reads the API key from the app manifest: <meta-data android:name="com.pocketradar.smartcoach.API_KEY" android:value="…" /> inside <application>.

Parameters

context

any context; the SDK keeps only the application context.

deviceConfigurationOptions

null uses the defaults.

Throws

SmartCoachError

SmartCoachErrorCode.alreadyConfigured on a second call, SmartCoachErrorCode.missingApiKey if the key is missing or not a UUID, SmartCoachErrorCode.invalidBundleId or SmartCoachErrorCode.invalidConfiguration.

fun configure(context: Context, firstParty: Boolean, deviceConfigurationOptions: SmartCoachDeviceConfigurationOptions? = null)

Configures the SDK for a PocketRadar first-party app. Not part of the partner API.

Identical to configure except that, when firstParty is true and the host app's package name is one PocketRadar owns, radar features are not gated by the entitlements service: scanning, connecting and measuring work for SmartCoach 1 and 2 with no network access and no token. For any other package the flag is ignored and entitlements are enforced exactly as for partners. The API key is still required.
