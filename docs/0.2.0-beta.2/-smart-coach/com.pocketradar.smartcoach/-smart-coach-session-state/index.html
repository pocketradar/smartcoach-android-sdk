SmartCoachSessionState

sealed interface SmartCoachSessionState

Where the SDK's single radar session is, as published by SmartCoach.sessionStateStream.

The session follows the radar: if it starts or stops measuring from its own button, the state moves between connected and measuring exactly as it does for SmartCoach.startMeasuring and SmartCoach.stopMeasuring.

SmartCoach.sessionStateStream().collect { state ->
    when (state) {
        is SmartCoachSessionState.disconnected -> showConnectButton(state.error)
        is SmartCoachSessionState.scanning -> showRadars(state.radars)
        is SmartCoachSessionState.connected, is SmartCoachSessionState.measuring -> showLive()
        else -> showProgress()
    }
}
